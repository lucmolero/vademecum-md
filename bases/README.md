# Bases

- `curated/legislacao/federal/`: textos normativos canônicos publicados;
- `history/`: versões e alterações que preservam a proveniência;
- `derived/`: catálogos, relações e relatórios regeneráveis;
- `raw/`: snapshots locais de aquisição, ignorados pelo Git.

Regulamentos, tratados e jurisprudência não fazem parte do corpus atual. Não há
pastas reservadas para essas camadas; veja o [escopo do produto](../docs/PRODUCT_SPEC.md)
e o [roadmap](../docs/ROADMAP.md) antes de propor expansão.
