# Curated

Um diploma por arquivo Markdown. O núcleo atual é legislação federal; regulamentos, tratados e jurisprudência terão camadas próprias.

Para localizar e abrir um diploma no GitHub, use o [índice completo da legislação federal](../../docs/INDICE_LEGISLACAO.md). Os arquivos seguem `legislacao/federal/{tipo}/{ano}/{arquivo}.md`; cada documento preserva seu próprio ID, fonte, hash, corte temporal e metadados no front matter. Consulte também a [pasta da legislação federal](legislacao/federal/) e os [grandes códigos](../../README.md#encontre-uma-lei).
