# Histórico técnico privado

Snapshots brutos, logs, comandos, hashes e evidências de aquisição não devem ser publicados no repositório autoral. O coletor grava esses dados em armazenamento técnico privado, e `build_private_ledger.py` exporta uma cópia verificável para o repositório privado de histórico.

O repositório público recebe somente metadados não sensíveis, hashes e relatórios regeneráveis. A análise jurídica autônoma decide o tratamento editorial; os validadores determinísticos verificam identidade, integridade, proveniência, estrutura e segurança. Nenhuma indisponibilidade de fonte autoriza a invenção ou a substituição silenciosa de texto.
