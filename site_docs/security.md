# Segurança

Workflows não confiáveis não recebem segredos. A branch padrão não é mutada
diretamente, fontes são restringidas por allowlist e snapshots privados não são
publicados. Consulte a [política de segurança](https://github.com/lucmolero/vademecum-md/blob/main/SECURITY.md)
e o [canal privado para vulnerabilidades](https://github.com/lucmolero/vademecum-md/security/advisories/new).
