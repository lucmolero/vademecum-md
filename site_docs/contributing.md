# Relatos e propostas públicas

O VadeMecum MD é uma publicação de leitura e consulta. O corpus publicado não é
editado pela interface do site, e um relato ou pull request não altera os
documentos automaticamente.

## Relatar um problema

- [Apontar divergência com fonte oficial](https://github.com/lucmolero/vademecum-md/issues/new?template=divergencia-normativa.yml)
  — informe o diploma, o dispositivo, a release e a evidência oficial.
- [Relatar link quebrado](https://github.com/lucmolero/vademecum-md/issues/new?template=link-quebrado.yml)
  — inclua o link, a release e o erro observado.
- [Relatar problema na interface](https://github.com/lucmolero/vademecum-md/issues/new?template=problema-interface.yml)
  — descreva os passos, o navegador e o dispositivo afetado.

Issues são canais de triagem para esses relatos. Não inclua dados pessoais,
documentos privados ou pedidos de orientação jurídica. Issues fora do escopo
podem ser fechadas.

## Propor uma alteração

As propostas integráveis vêm do mantenedor, do Dependabot e da rotina interna
de atualização legislativa. Pull requests de outras contas são fechados
automaticamente; os formulários de issue são o canal para relatos públicos.
Alterações no corpus devem indicar fonte
oficial, dispositivo, data de corte e evidências de fidelidade. A revisão
jurídica e os gates técnicos do repositório continuam obrigatórios; a branch
padrão não recebe atualização direta por meio do site.

Consulte o [guia de contribuição e manutenção no GitHub](https://github.com/lucmolero/vademecum-md/blob/main/CONTRIBUTING.md)
para os critérios e as validações do repositório.
