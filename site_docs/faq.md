# Perguntas frequentes

## O VadeMecum MD é uma publicação oficial?

Não. É um corpus autoral derivado de fontes públicas oficiais. A fonte oficial
continua sendo a referência normativa.

## O projeto contém toda a legislação brasileira?

Não. O escopo atual é um corpus federal curado, com cobertura mensurável. A
matriz, os status e os relatórios mostram o que está incluído e o que ainda
exige reconciliação.

## Por que alguns documentos estão em `review`?

Porque possuir uma URL e um hash não prova, sozinho, equivalência normativa.
O estado `review` impede que uma redação ainda não comparada seja apresentada
como plenamente validada.

## O site é a fonte normativa?

Não. O site é uma renderização derivada. O Markdown canônico e seus metadados
formam a fonte de dados do projeto.

## O projeto oferece aconselhamento jurídico?

Não. A curadoria organiza evidências normativas e não substitui análise
profissional aplicada a um caso concreto.
