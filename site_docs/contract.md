# Contrato dos documentos

Cada diploma possui frontmatter YAML com identidade, vigência, corte temporal,
fonte, unidade de extração, hashes e estado de fidelidade.

Os estados de texto são `texto_original`, `texto_consolidado`,
`texto_consolidado_com_anotacoes_oficiais` e `texto_historico`. O estado
`consolidada_fonte_oficial` só é usado quando a redação vigente é identificável
na fonte oficial.
